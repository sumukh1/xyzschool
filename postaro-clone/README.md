# Postaro-style Ecommerce Homepage (Static)

This is a static, original implementation of a modern ecommerce homepage UI inspired by Postaro's layout. It uses vanilla HTML, CSS, and JavaScript with placeholder images and mock data.

## Quick Start

- Open `index.html` in your browser, or serve the folder with any static server.
- Files:
  - `index.html` – main markup
  - `styles.css` – styles and responsive layout
  - `script.js` – interactions (carousel, search suggestions, cart counter)
  - `assets/logo.svg` – placeholder logo

## Notes

- All assets are placeholders from Unsplash/DummyImage or simple SVG. Replace with your brand assets and product images.
- No backend: cart/search are demo interactions only.
- You can adapt the color theme by editing CSS variables in `styles.css` under `:root`.

## Deploy

You can deploy to any static hosting (GitHub Pages, Netlify, Vercel). On Netlify/Vercel, just point to the repository; no build step required.
